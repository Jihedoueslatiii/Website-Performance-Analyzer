# 🔍 InsightWeb Pro

A website analyzer that tells you **exactly** why you lost points — not just a score.

Performance. SEO. Accessibility. Best practices. All broken down with point impact.

Built with Flask + Playwright.

---

## 📦 What It Does

- Audits any website
- Shows performance metrics (TTFB, FCP, load time)
- Checks SEO, accessibility, best practices
- Gives point-by-point breakdown of issues
- Captures screenshot preview

---

## 🚀 Quick Start

```bash
# Clone
git clone https://github.com/jihedoueslati/insightweb-pro.git
cd insightweb-pro

# Install
pip install -r requirements.txt
python -m playwright install chromium

# Run
python app.py


Open http://localhost:5000
